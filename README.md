# Web Scraping Projects Collection

## Overview
This repository contains multiple Web Scraping projects developed using Python. The projects demonstrate how to collect, extract, and process data from websites using various Python libraries such as BeautifulSoup, Requests, Newspaper3k, and Pandas.

The projects focus on extracting structured information from websites including:
- Product details from E-commerce websites
- News articles from online news portals
- Company and Wikipedia data
- Web page HTML content analysis

These projects help in understanding real-world data extraction, HTML parsing, and data preprocessing techniques used in Data Analytics and Machine Learning workflows.

---

## Projects Included

### Amazon Product Data Scraper
Extracts product information such as:
- Product Title
- Price
- Ratings
- Number of Reviews
- Availability Status

The scraped data is stored in CSV format for further analysis.

Project uses:
- Requests
- BeautifulSoup
- Pandas

---

### 2️News Article Scraper
Scrapes news articles and extracts:
- Article Title
- Authors
- Publish Date
- Article Content

The project uses the `newspaper3k` library to automatically extract readable news content from websites.

Project uses:
- Newspaper3k
- Feedparser
- Requests

---

### Wikipedia Web Scraper
Extracts HTML content and structured information from Wikipedia pages for analysis and data collection.

Features:
- Fetch page content
- Parse HTML
- Extract tables and text
- Analyze web structure

Project uses:
- Requests
- BeautifulSoup
- Pandas
